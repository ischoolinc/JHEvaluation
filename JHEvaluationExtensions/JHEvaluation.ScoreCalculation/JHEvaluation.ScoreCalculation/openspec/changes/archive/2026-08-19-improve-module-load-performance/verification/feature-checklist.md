# 模組載入功能驗證清單

每個部署模式（新竹、高雄）及有權限／無權限帳號都需執行適用項目。

## 學生功能

- [ ] 「教務／成績作業」存在；未選學生時停用，選取學生後依 `JHSchool.Student.Ribbon0057` 啟用。
- [ ] 計算科目成績、計算領域成績、計算學習領域成績、加總學習領域文字描述可開啟原表單。
- [ ] 「教務／畢業作業／計算畢業成績」依選取狀態及 `JHSchool.Student.Ribbon0057` 啟用並可開啟。
- [ ] 「畢業資格審查」依選取狀態及 `JHSchool.Student.Ribbon0058` 啟用並可開啟。
- [ ] 成績相關與學務相關兩處「畢業預警報表」依 `JHSchool.Student.Report0010` 啟用且行為一致。

## 教務功能

- [ ] 「批次作業／檢視／成績作業」為大型選單並顯示原圖示。
- [ ] 產生學期歷程依 `JHSchool.EduAdmin.Ribbon.BatchSemesterHistory` 啟用並可開啟。
- [ ] 四個批次成績計算功能依 `JHSchool.EduAdmin.Ribbon0045` 啟用並可開啟原表單。
- [ ] 「畢業作業」為大型選單；隱藏的計算畢業成績維持隱藏。
- [ ] 教務畢業資格審查依 `JHSchool.EduAdmin.Ribbon0046` 啟用並可開啟。

## 框架擴充點

- [ ] 權限管理出現「教務作業／批次產生學期歷程」。
- [ ] 學生資料項目包含學期成績、畢業成績及修課成績，且不重複。
- [ ] 畢業成績 detail builder 只註冊一次。
- [ ] 資料合理性檢查包含學期歷程與學期成績學年度學期檢查，且不重複。

## 可靠性與診斷

- [ ] 同一宿主生命週期第二次呼叫 `Program.Main()` 不新增選單、handler、detail item 或檢查器。
- [ ] 正常載入產生七個階段及 `total` 的成功紀錄。
- [ ] 注入任一階段失敗時，該階段與 `total` 記為失敗，且初始化例外仍向宿主傳遞。
- [ ] `JH_SCORE_LOAD_DIAGNOSTICS=0` 時功能結果不變，CSV 僅保留 `total`。
- [ ] CSV 路徑無法寫入時，模組仍依原初始化結果載入，並可從 `Trace` 看到診斷輸出失敗。
