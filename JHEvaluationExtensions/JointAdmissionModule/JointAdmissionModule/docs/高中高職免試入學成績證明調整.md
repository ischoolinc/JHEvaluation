# 高中高職免試入學成績證明調整

## 修改日期

2026-07-13

## 修改檔案

* `Program.cs`

## 原始行為

* 高雄模式（`Mode == ModuleMode.KaoHsiung`）會註冊並顯示「高雄區高中高職免試入學成績證明」。
* 竹苗區、台南區、中投區報表在所有模式下皆會註冊並顯示。
* 高雄模式會額外註冊高雄區報表權限項目。

## 新行為

* 任一模式下皆不註冊、不顯示「高雄區高中高職免試入學成績證明」。
* 「台南區高中高職免試入學成績證明」在所有模式下皆註冊並可用。
* 「竹苗區高中高職免試入學成績證明」「中投區高中高職免試入學成績證明」僅在非高雄模式（`Mode != ModuleMode.KaoHsiung`）註冊並可用。
* 不再註冊高雄區報表權限項目；其餘報表仍沿用既有 `PermissionCodeRpt_HsinChu` 權限與選取學生啟用邏輯。

## 模式報表可用性矩陣

| Module Mode            | 高雄區報表 | 竹苗區報表 | 台南區報表 | 中投區報表 |
| ---------------------- | ---------- | ---------- | ---------- | ---------- |
| `ModuleMode.KaoHsiung` | Hidden     | Hidden     | Available  | Hidden     |
| Non-Kaohsiung          | Hidden     | Available  | Available  | Available  |

## 條件變更摘要

1. 移除高雄模式對高雄區報表的權限註冊與選單註冊。
2. 台南區報表維持無條件註冊。
3. 竹苗區、中投區報表改為僅在 `Mode != ModuleMode.KaoHsiung` 時註冊。
4. 保留既有報表建構參數（`ModuleMode.HsinChu` / `Tainan` / `Taichung`）、選取學生檢查與權限啟用邏輯。

## 未更動範圍確認

本次僅調整報表功能啟用／選單註冊條件，未修改：

* `DeployModeSetup()`、`ModuleMode`
* 學生資料項目、右鍵選單
* 報表內容或計算邏輯
* 既有點擊事件與表單呼叫行為
* 其他無關邏輯或註解

## 編譯／驗證結果

* 專案建置成功：`JointAdmissionModule.dll`（0 錯誤；既有警告與本次修改無關）。
* 無重複註冊選單事件處理常式。
* 依程式碼條件：高雄模式僅註冊台南區報表；非高雄模式註冊竹苗、台南、中投區報表；高雄區報表兩種模式皆不註冊。
* 可用報表仍以 `PermissionCodeRpt_HsinChu` 與學生選取狀態控制按鈕啟用。
