# 評量成績(固定排名)調整 0617

## Goal

When report configurations are loaded, check whether each of the four built-in default configurations uses the same template as the corresponding embedded Resource template. If the saved template is missing or has different merge fields, replace it with the Resource template and save it back.

## Files changed

- `PrintForm.cs`

## Methods added

1. `GetDefaultResourceTemplate(string configName)`
   - Returns a new `Document` from the embedded Resource for the four default configuration names.
   - Returns `null` for custom or non-default configurations.

2. `GetTemplateMergeFieldNames(Document document)`
   - Collects all mail merge field names from a document, including duplicate occurrences.
   - Trims spaces from each field name.

3. `ParseMergeFieldName(string fieldCode)`
   - Parses a `MERGEFIELD` field code to extract the field name.

4. `IsSameTemplateMergeFields(Document currentTemplate, Document resourceTemplate)`
   - Compares merge field name lists (including duplicates).
   - Sorts field names with ordinal comparison before comparing.

5. `SyncDefaultTemplateFromResource(Configure conf)`
   - Loads the saved template if needed (`Decode()`).
   - Compares with the Resource template.
   - Replaces, encodes, and saves when missing or different.
   - Returns `true` when a sync was performed.

## Where sync is called

In `PrintForm.bkw_DoWork`, immediately after:

```csharp
_ConfigureList = _AccessHelper.Select<Configure>();
```

Added:

```csharp
foreach (Configure conf in _ConfigureList)
{
    SyncDefaultTemplateFromResource(conf);
}
```

## Notes and risks

- Comparison is based on mail merge field names (including duplicate counts), not full Word binary content. This avoids false mismatches from Word metadata differences while still detecting missing or renamed fields.
- If a school intentionally customized a default configuration's template via "Change Mail Merge Template", the next load will overwrite it with the embedded Resource template when merge fields differ. This is intentional for the four built-in default names.
- `Decode()` failures (e.g. corrupted template data) are treated as a missing template and replaced with the Resource template.
